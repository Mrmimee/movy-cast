# Movy Cast

极简、干净的 `movy.sx` 浏览器电视投屏（DLNA）与中文字幕助手。

## 核心特性
- **原生融入右下角控制栏**：纯白图标对齐全屏按钮左侧；弹窗与影院字幕均采用 Shadow DOM 样式隔离，0ms 缓存秒开，点击外部 / `Esc` 自动关闭。
- **国产电视 DLNA 投屏 & 流畅缓冲**：零依赖纯 Node.js 本地桥接，自动发现局域网电视，内置 Keep-Alive 连接池、HLS 3 分片内存预加载缓冲，以及仅海外拉流自动跟随 Windows 系统代理。
- **FFmpeg 无损重封装 & 硬件字幕压制**：检测到本机已安装 FFmpeg 时，自动以 `-c copy` 无损重封装解决海信/OPPO 等国产电视黑屏；携带中文字幕投屏时自动调用 GPU 硬件编码器（NVENC/QSV/AMF）实时压制影院级中文字幕，确保 100% 电视出字。
- **双向进度同步（账号观看记录）**：投屏时自动带入电脑当前进度，观看期间每 15 秒及停止投屏前静默把电视进度回写给暂停中的网页播放器，自动同步至 `movy.sx` 登录账号观看记录。
- **随网站自动启停**：基于 Chrome / Edge Native Messaging，打开 `movy.sx` 自动拉起，关掉标签页后空闲自动退出。
- **精校中文字幕 + 去广告清洗**：内置迅雷云端精校中文字幕源（简体优先，支持 `.ass`/`.srt`/`.vtt` 与 UTF-8/GBK 防乱码，自动过滤广告水印行与缩略图伪字幕），独立开关可控，网页端与电视投屏同步生效。
- **音画 / 字幕同步校准**：支持原字幕时间轴比对 / 听声对齐一键校准，以及 `±0.1s` / `±0.5s` 精调并按片记忆。

## 新电脑部署（3 步）

### 1. 环境依赖（Windows）
- **Node.js**（必需）：用于运行零依赖本地 DLNA 桥接。
- **FFmpeg（强烈推荐，解决海信等国产电视 fMP4 黑屏）**：
  ```powershell
  winget install -e --id Gyan.FFmpeg.Essentials
  ```
  安装后无需配置环境变量或重启电脑，桥接会自动识别（不投屏时零后台占用）。

### 2. 注册按需自动启动（仅需运行一次）
- 双击运行 `bridge/install-autostart.bat`（支持 Chrome / Edge，无需管理员权限）。
- 脚本会自动按当前电脑路径生成 `bridge/com.movy.cast.json` 并写入当前用户注册表。
- 首次唤起如弹出 Windows 防火墙提示，请允许「专用网络」访问。
- 如需卸载自动启动：双击 `bridge/uninstall-autostart.bat`。

### 3. 加载浏览器插件
1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目的 `extension` 文件夹

## 使用注意点
- **代理软件配合**：使用 Clash / Mihomo 等代理时，建议**关闭 TUN 模式**（防止拦截局域网 UDP 发现电视）并**开启「系统代理」**，桥接会自动让海外视频流走系统代理，同时保持局域网与电视 100% 直连。
- **不要移动项目目录**：注册自动启动后，若把项目文件夹移到其他路径，重新双击一次 `bridge/install-autostart.bat` 即可更新路径。
- **隐私与仓库安全**：含本机路径的 `bridge/com.movy.cast.json` 已被 `.gitignore` 忽略，不会上传至 GitHub。
- **进度控制**：在 FFmpeg 无损重封装模式下，请直接拖动插件面板内的进度条跳转（自动从目标时间点续播）。
